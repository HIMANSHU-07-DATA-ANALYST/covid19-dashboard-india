# covid19-dashboard-india
A data visualization project analyzing COVID-19 trends in India using real-world data.
📊 COVID-19 Dashboard: India Analysis
This project visualizes the impact of COVID-19 across Indian states using demographics and state-wise metrics. Built using data visualization tools like Power BI (or Excel), this dashboard includes:

🔍 Key Insights:
Total Deaths by State (Map)

Age-Wise Case Distribution (Donut Chart)

Gender-wise Breakdown

State-Wise Testing Trends

Vaccine Doses Administered (Covishield, Covaxin, Sputnik V)

ICMR Lab Coverage by State

📌 Skills Used:
Power BI / Excel (Charts, Maps, KPIs)

Data Cleaning

Visualization Design

Public Health Data Interpretation
